# Weather App

A simple weather application built using HTML, CSS, and JavaScript.<br />

## About

This project was created while following the Codedex Weather App tutorial to practice front-end web development concepts and working with weather APIs.<br />
Tutorial:<br />
https://www.codedex.io/projects/view-weather-with-html-css-js<br />

## Features

- Fetches weather information using an API<br />
- Displays:<br />
  - Temperature<br />
  - Weather conditions<br />
  - Location details<br />
- Responsive user interface<br />

## Technologies Used

- HTML<br />
- CSS<br />
- JavaScript<br />
- Weather API<br />

## Main Learning Inputs

- API requests using JavaScript<br />
- Handling JSON data<br />
- DOM manipulation<br />
- Asynchronous programming with `fetch()`<br />
- Building responsive web interfaces<br />

## Future Improvements

- Support multiple countries<br />
- Dynamic country code selection<br />
- 5-day weather forecast<br />
- Dark mode<br />
- Geolocation support<br />

## Disclaimer

This project was built as part of a learning exercise by following the Codedex Weather App tutorial. The code has been used for educational purposes and will be extended with additional features and improvements over time.
